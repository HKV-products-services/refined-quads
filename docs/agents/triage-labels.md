# Triagelabels

De skills werken met vijf vaste triagerollen. Dit bestand koppelt die rollen aan
de labels die in deze repo worden gebruikt. Met de lokale issue-tracker (zie
`issue-tracker.md`) staat het label in de regel `Status: <label>` bovenaan het
issuebestand, niet als GitHub-label.

| Label in mattpocock/skills | Label in onze tracker | Betekenis                                        |
| -------------------------- | --------------------- | ------------------------------------------------ |
| `needs-triage`             | `needs-triage`        | Moet nog door de beheerder beoordeeld worden     |
| `needs-info`               | `needs-info`          | Wacht op meer informatie van de melder           |
| `ready-for-agent`          | `ready-for-agent`     | Volledig uitgewerkt, klaar voor een AFK-agent    |
| `ready-for-human`          | `ready-for-human`     | Moet door een mens worden gebouwd                |
| `wontfix`                  | `wontfix`             | Wordt niet opgepakt                              |

Als een skill een rol noemt (bijv. "apply the AFK-ready triage label"), gebruik
dan het bijbehorende label uit deze tabel.

Pas de rechterkolom aan als je andere woorden gaat gebruiken.
