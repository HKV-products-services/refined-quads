Use the mesh in D-HYDRO

WarningDo not call it mesh next to D-HyDAMO

D-HyDAMO scripts usually import from hydrolib.dhydamo.geometry import mesh (the module with mesh2d_clip, links1d2d_add_links_1d_to_2d and so on). mesh = generate(...) replaces that module, and the next mesh.<function>(...) fails with an AttributeError. Use another name, such as quad_mesh in the examples here.

Write a net file

from refined_quads import write_ugrid

write_ugrid(quad_mesh, workdir / "mesh_net.nc")

The file is UGRID-1.0 with the structure of the D-HYDRO mesh generator export: the Mesh2d topology with nodes, edges and faces, edge and face coordinates and face bounds. For EPSG:28992 the CRS variable has exactly the attributes of the D-Flow FM plugin; for another projected CRS they are derived with pyproj; a mesh without CRS gets no CRS variable.

variables: projected_coordinate_system, Mesh2d, Mesh2d_node_x, Mesh2d_node_y, Mesh2d_face_nodes, Mesh2d_edge_nodes, Mesh2d_edge_x, Mesh2d_edge_y, Mesh2d_face_x, Mesh2d_face_y, Mesh2d_face_x_bnd, Mesh2d_face_y_bnd
CRS: Amersfoort / RD New (EPSG 28992)

Bed levels

The net file has no bed level (no Mesh2d_node_z or Mesh2d_face_z). Give the bed level to D-Flow FM as samples: a file bodem_2d.xyz with x y z on every cell centre, and two [Initial] blocks at the top of the field file (after [General]), with bedLevType = 1 in the MDU:

[Initial]
quantity            = bedlevel
dataFile            = bodem_2d.xyz
dataFileType        = sample
interpolationMethod = averaging
operand             = O
averagingType       = nearestNb
averagingRelSize    = 3.0
averagingNumMin     = 1
extrapolationMethod = 0
locationType        = 2d

[Initial]
quantity            = bedlevel
dataFile            = bodem_2d.xyz
dataFileType        = sample
interpolationMethod = averaging
operand             = O
averagingType       = nearestNb
averagingRelSize    = 1.0
averagingNumMin     = 1
extrapolationMethod = 0
locationType        = 2d

The first block fills every cell from the nearest sample in a wide area, also cells that have no sample of their own; the second gives each cell the value on its own centre. A bed level per cell in the net file does not work in the D-HYDRO GUI: the GUI rebuilds the cells from nodes and edges and closes small gaps, after which the list no longer fits the cells and the import fails (see ADR-0003). Without samples D-Flow FM uses BedLevUni everywhere, without a warning.

With D-HyDAMO

When the mesh is read with mesh2d_from_netcdf and the bed level comes from a raster (mesh2d_altitude_from_raster(network, raster, "face", ...)), hydrolib writes it as mesh2d_face_z. Turn it into samples around saving the model. Before dimr.save(recurse=True):

import numpy as np

m2d = fm.geometry.netfile.network._mesh2d
fz = np.asarray(m2d.mesh2d_face_z, dtype=float)
ok = np.isfinite(fz) & (fz > -999)
bodem_xyz = np.column_stack([m2d.mesh2d_face_x, m2d.mesh2d_face_y, fz])[ok]
fm.geometry.bedlevtype = 1

After saving: write the samples, remove mesh2d_face_z from the net file (netCDF4 cannot delete a variable, so the rest is copied), and put the two blocks above at the top of the field file:

import os, re
import netCDF4

dfm_dir = Path(output_path) / "dflowfm"
np.savetxt(dfm_dir / "bodem_2d.xyz", bodem_xyz, fmt="%.3f %.3f %.4f")

net = dfm_dir / Path(str(fm.geometry.netfile.filepath)).name
tmp = net.with_name(net.stem + "_tmp.nc")
with netCDF4.Dataset(net) as src, netCDF4.Dataset(tmp, "w", format=src.file_format) as dst:
    for ds in (src, dst):
        ds.set_auto_maskandscale(False)
        ds.set_auto_chartostring(False)
    dst.setncatts(src.__dict__)
    for name, dim in src.dimensions.items():
        dst.createDimension(name, None if dim.isunlimited() else len(dim))
    for name, var in src.variables.items():
        if name.lower() == "mesh2d_face_z":
            continue
        atts = dict(var.__dict__)
        fill = atts.pop("_FillValue", None)
        dst.createVariable(name, var.datatype, var.dimensions, fill_value=fill).setncatts(atts)
        dst[name][...] = var[...]
os.replace(tmp, net)

block = """[Initial]
quantity            = bedlevel
dataFile            = bodem_2d.xyz
dataFileType        = sample
interpolationMethod = averaging
operand             = O
averagingType       = nearestNb
averagingRelSize    = {}
averagingNumMin     = 1
extrapolationMethod = 0
locationType        = 2d

"""
ini = dfm_dir / "fieldFile.ini"
text = ini.read_text() if ini.exists() else "[General]\nfileVersion = 2.00\nfileType    = iniField\n\n"
m = re.search(r"^\[(?!general\])", text, re.M | re.I)  # the first block after [General]
i = m.start() if m else len(text)
ini.write_text(text[:i] + block.format(3.0) + block.format(1.0) + text[i:])

# hydrolib leaves iniFieldFile out of the MDU when the model had no field file
mdu = dfm_dir / Path(str(fm.filepath)).name
t = mdu.read_text()
if not re.search(r"(?im)^\s*iniFieldFile\s*=\s*[^\s#]", t):
    t = re.sub(r"(?im)^\s*iniFieldFile\s*=.*\n", "", t)
    t = re.sub(r"(?im)^(\[geometry\][^\n]*\n)", r"\1iniFieldFile = fieldFile.ini\n", t, count=1)
    mdu.write_text(t)

Other bed level blocks in the field file come after these two and overwrite them where they have values, for example a fixed bed level per polygon.

Bed level on the nodes

To give the bed level on the nodes instead (bedLevType 3 to 6), sample the raster on the nodes and write it as mesh2d_node_z. The nodes do not change when the GUI rebuilds the cells, so a value per node always fits; no sample file is needed. Before dimr.save(recurse=True):

import types
import numpy as np

# hydrolib fills NaN's (nodes on the edge, partly outside the raster) in place, but
# pandas 3 returns read-only arrays: let the raster statistics return writable copies
_stats = mesh.rasterstats.raster_stats_fine_cells
if not getattr(_stats, "_writable", False):
    def _writable_stats(*args, **kwargs):
        df = _stats(*args, **kwargs)
        return {c: types.SimpleNamespace(values=df[c].to_numpy(copy=True)) for c in df.columns}
    _writable_stats._writable = True
    mesh.rasterstats.raster_stats_fine_cells = _writable_stats

network = fm.geometry.netfile.network
mesh.mesh2d_altitude_from_raster(network, rasterpath, "node", "mean", fill_option="nearest")
m2d = network._mesh2d
if len(m2d.mesh2d_face_z) != len(m2d.mesh2d_face_x):  # a stale face_z breaks the save
    m2d.mesh2d_face_z = np.empty(0)
fm.geometry.bedlevtype = 3  # 3 mean, 4 minimum, 5 maximum of the node values

After saving, remove mesh2d_face_z from the net file as above (the block up to os.replace(tmp, net)): hydrolib always writes it, and the GUI reads it and fails on its rebuilt cells. Leave out the [Initial] bedlevel blocks: they would overwrite the nodes. Tested with D-Flow FM 2026.02: every cell gets a bed level between the lowest and the highest of its node values.

Which bedLevType

“Face” means two opposite things here. In the net file (UGRID 1.0) a face is a cell: mesh2d_face_z is a level per cell. In the description of bedLevType in the MDU, “at face” means at a cell side through which water flows (a flow link or u-point), the finite-volume meaning. This table uses cell, cell side and node only.

bedLevType Input Level of a cell side Bed level of the cell
1 per cell: samples (or mesh2d_face_z) not measured (MDU: the higher of the two cells) the cell’s own value
2 per cell side: samples the sample not measured
3 per node: mesh2d_node_z mean of its two nodes the lowest of its cell sides
4 per node the lower of its two nodes the lowest of its cell sides, so its lowest node
5 per node the higher of its two nodes the lowest of its cell sides
6 per node not measured mean of its nodes

Only cell sides shared with another cell count; sides on the edge of the mesh do not. The cell formulas were measured with D-Flow FM 2026.02 on a mesh of 849 cells: each matches the bed level D-Flow FM uses in every cell to 0.1 mm. In short: 1 gives each cell exactly its own value; 6 the mean of its nodes; 4 its lowest node; with 3 and 5 one low cell side makes the whole cell low.

NoteNet files written by refined-quads 0.1.x

These contain Mesh2d_node_z with -999. After a clip with MeshKernel that array keeps its old length and saving fails with “shape mismatch”. Before saving, empty it: if len(m2d.mesh2d_node_z) != len(m2d.mesh2d_node_x): m2d.mesh2d_node_z = np.empty(0).

TipGeoTIFF fields in the D-HYDRO GUI

The GUI only reads rasters with the extension .tif (or .asc); with .tiff it stops at “reading spatial operations”. D-Flow FM and DIMR read both.

Read a net file

read_ugrid reads only the 2D mesh of a net file; a 1D network and other variables in it are ignored. The lattice is derived from the square cells, so you can check or refine a mesh from any program:

from refined_quads import check, read_ugrid

quad_mesh = read_ugrid(workdir / "mesh_net.nc")
print(check(quad_mesh).summary())

If the orthogonality repair does not close

D-Flow FM rejects a network whose edges are not orthogonal enough. The generator repairs such edges; if that does not close, generate raises OrthogonalityRepairError with the raw mesh (exc.mesh) and the problem locations (exc.bad_points), and the command line writes <output>_raw.nc and <output>_problems.gpkg next to the output so you can look at them in QGIS.
